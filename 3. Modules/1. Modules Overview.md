# Node.js Modules — Simple Summary

A **module** in Node.js is a reusable piece of code that performs a specific task. Modules help organize code, make it easier to maintain, and allow functionality to be shared across different files.

## Key Points

* A module can contain functions, objects, variables, or other functionality.
* Modules help keep code organized and reusable.
* Node.js supports three main types of modules:

  * **Internal (Built-in) Modules**
  * **User-Created Modules**
  * **Third-Party Modules**

## Types of Modules

### 1. Internal (Built-in) Modules

These modules come with Node.js and do not require installation.

Example:

* `http` → create web servers
* `fs` → work with files
* `path` → handle file paths

Usage:

```js
const http = require('http');
```

### 2. User-Created Modules

These are modules you create yourself to organize and reuse your code.

Example:

```js
// math.js
function add(a, b) {
  return a + b;
}

module.exports = add;
```

```js
// index.js
const add = require('./math');

console.log(add(2, 3)); // 5
```

This allows functionality to be separated into different files and reused throughout the application.

### 3. Third-Party Modules

These are packages created by other developers and distributed through npm.

Example:

* `axios` → make HTTP requests
* `express` → build web applications

Usage:

```js
const axios = require('axios');
```

Third-party modules must usually be installed first:

```bash
npm install axios
```

## Exporting Modules

To make code available to other files, you must **export** it.

CommonJS (traditional Node.js):

```js
module.exports = myFunction;
```

You can export:

* Functions
* Objects
* Classes
* Variables

Example:

```js
module.exports = {
  log() {
    console.log("Hello");
  }
};
```

## Importing Modules

To use code from another module, you **import** it.

### CommonJS

```js
const logger = require('./logger');
```

### ES Modules (Modern JavaScript)

```js
import { add } from './math.js';
```

Modern Node.js supports both approaches, though ES Modules are becoming increasingly common.

## Why Modules Matter

Modules help developers:

* Organize code into smaller files
* Reuse functionality
* Improve maintainability
* Reduce duplication
* Build larger and more scalable applications

## Common Flow

1. Create functionality in a file.
2. Export it.
3. Import it where needed.
4. Reuse it throughout the application.

## One-Sentence Summary

**A module is a reusable piece of code in Node.js that helps organize applications, share functionality between files, and build scalable software using built-in, custom, or third-party code.**
