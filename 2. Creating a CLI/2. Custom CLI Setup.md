## Creating a CLI (Node.js) — Simple Summary

A CLI (Command Line Interface) lets you run your program using terminal commands instead of clicking buttons or using a UI.

In this lesson, you’re setting up a simple CLI for a note-taking app using Node.js.

---

## Key Idea

You are turning a JavaScript file into a terminal command like:

```
note
```

So instead of running:

```
node index.js
```

you can just type `note`.

---

## Step 1: Initialize a Node.js project

You start by creating a Node.js project:

```
npm init
```

This creates a `package.json` file, which stores project settings and configuration.

---

## Step 2: Create your main file

You create a file called:

```
index.js
```

At first, it just contains something simple like:

```
console.log("Hello CLI")
```

This is just to test that your command works later.

---

## Step 3: Register a CLI command

In `package.json`, you add a `bin` field:

```
{
  "name": "note",
  "bin": {
    "note": "./index.js"
  }
}
```

### What this means:

* `"note"` is the command you will type in the terminal
* `"./index.js"` is the file that runs when the command is used

So Node now knows:

> When user types `note`, run `index.js`

---

## Step 4: Add a hashbang (important line)

At the very top of `index.js`, you add:

```
#!/usr/bin/env node
```

### What it does:

This tells your computer:

> “Use Node.js to run this file”

Without this, the system might not know what interpreter to use.

---

## Step 5: Link your CLI to your system

Instead of installing your CLI globally, you use:

```
npm link
```

### What this does:

It creates a **symbolic link (symlink)**, which basically means:

> “Pretend this project is installed globally so I can run it anywhere”

Now your command works from any folder.

---

## Step 6: Run your CLI

Now you can simply type:

```
note
```

And it runs your `index.js` file.

---

## Why this matters

This is the foundation of building real developer tools.

It allows you to:

* Turn Node.js scripts into real terminal commands
* Build tools like Git-style CLIs
* Accept inputs later (arguments & flags)
* Create full developer utilities

---

## One-Sentence Summary

Creating a CLI in Node.js means turning a JavaScript file into a terminal command using `package.json` bin configuration, a hashbang (`#!/usr/bin/env node`), and `npm link` to make it runnable globally on your system.
