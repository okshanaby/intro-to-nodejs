## Creating a CLI (Node.js) — Combined Simple Summary

A CLI (Command Line Interface) lets you run your program using terminal commands instead of a graphical interface. In this lesson, you’re building the foundation of a note-taking CLI using Node.js.

---

## Key Idea

You are turning a JavaScript file into a real terminal command like:

```text
note "this is my note"
```

---

## 1. Setting up the CLI

First, you initialize a Node.js project:

```bash
npm init
```

This creates a `package.json` file, which stores configuration for your project.

---

## 2. Creating the entry file

You create a file:

```text
index.js
```

At first, it just runs simple code like:

```text
console.log("Hello CLI")
```

---

## 3. Registering the CLI command

In `package.json`, you add:

```json
{
  "name": "note",
  "bin": {
    "note": "./index.js"
  }
}
```

### What this means:

* `note` becomes your terminal command
* It runs `index.js` when executed

---

## 4. Adding the hashbang

At the top of `index.js`:

```text
#!/usr/bin/env node
```

### Why it’s needed:

It tells the system:

> “Run this file using Node.js”

---

## 5. Linking the CLI locally

Instead of installing globally, you run:

```bash
npm link
```

This creates a symbolic link so your command works anywhere in your terminal.

Now you can run:

```text
note
```

---

## 6. Reading input from the terminal (Note logic)

Now you start making the CLI actually useful by accepting input.

Node gives you access to command-line arguments through:

```js
process.argv
```

### Example code:

```js
// index.js
const note = process.argv[2];

const newNote = {
  id: Date.now(),
  note,
};

console.log("your new note", newNote);
```

---

## How it works

When you run:

```text
note "this is my note"
```

* `"this is my note"` becomes `process.argv[2]`
* The CLI stores it in a variable called `note`
* It creates a simple note object with:

  * `id` (timestamp)
  * `note` (user input)
* Then logs it

---

## Important detail (quotes)

Using quotes matters:

```text
note "this is my note"
```

Without quotes:

```text
note this is my note
```

The terminal treats each word as a separate argument.

---

## What’s next (why this is incomplete)

Right now, the CLI:

* Can read input
* Can create a note object

But it still needs:

* Saving notes somewhere (storage)
* More structured data (tags, names, status)
* Multiple commands (add, list, remove, etc.)
* Better argument/flag handling

Instead of building all that manually, developers usually use **third-party modules** to handle CLI parsing more efficiently.

---

## One-Sentence Summary

This step extends a Node.js CLI by reading terminal input using `process.argv`, turning it into a note object, and preparing for more advanced features like saving data and handling multiple commands with better tooling.
