# What is a Server? — Simple Summary

A **server** is a program that waits for requests from other programs (called **clients**) and sends back a response.

In Node.js, a server listens for incoming network requests and responds by running code, returning data, or performing some action.

Servers are the foundation of web applications because they allow communication between clients (websites, mobile apps, etc.) and backend services such as databases.

## Example: Simple Node.js Server

```js
const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello, World!');
});

server.listen(3000, () => {
  console.log('Server running on port 3000');
});
```

## How This Code Works

### Import the HTTP Module

```js
const http = require('http');
```

The built-in `http` module provides tools for creating web servers.

### Create the Server

```js
const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello, World!');
});
```

When a request arrives:

* `req` contains information about the incoming request.
* `res` is used to send a response back to the client.

The server:

1. Sets the status code to `200` (success).
2. Sets the response type to plain text.
3. Sends `"Hello, World!"` to the client.

### Start Listening

```js
server.listen(3000, () => {
  console.log('Server running on port 3000');
});
```

The server starts listening on port `3000`.

When the server starts successfully, the message below is printed:

```text
Server running on port 3000
```

## Server vs Client

### Server

A server is responsible for:

* Managing data
* Processing requests
* Handling business logic
* Communicating with databases
* Running continuously

### Client

A client is responsible for:

* Displaying information to users
* Collecting user input
* Sending requests to servers
* Running only when the user is interacting with the application

Examples of clients:

* Websites
* Mobile apps
* Desktop applications

## Why Servers Usually Run on Different Machines

Servers are often hosted on separate machines from clients because they:

* Handle many users at the same time
* Perform heavy computations
* Store and manage data
* Need to be available 24/7

This separation allows the client to remain fast and responsive while the server handles the heavy work.

## Request–Response Flow

```text
Client (Browser/App)
         │
         │ Request
         ▼
      Server
         │
         │ Process Request
         ▼
     Database
         │
         │ Data
         ▼
      Server
         │
         │ Response
         ▼
Client (Browser/App)
```

## Key Points

* A server is a program that listens for requests and sends responses.
* Node.js can be used to create servers using the built-in `http` module.
* Servers manage data, logic, and communication with databases.
* Clients focus on displaying information and interacting with users.
* Servers usually run on separate machines and remain available continuously.
* Modern web applications depend on servers to connect clients with backend services.
