# Vanilla Server — Simple Summary

A **Vanilla Server** is a basic web server created using Node.js's built-in `http` module without using frameworks like Express.

In this project, the server:

1. Reads notes from your application.
2. Converts them into HTML.
3. Inserts them into an HTML template.
4. Serves the webpage in a browser.
5. Automatically opens the browser when the server starts.

---

## Install Required Package

```bash
npm i open
```

### What it does

The `open` package automatically opens the default web browser from your Node.js application.

Example:

```js
open('http://localhost:5000')
```

This launches the website automatically.

---

## HTML Template

Create a file called:

```text
src/
└── template.html
```

This file acts as the layout of your webpage.

Example:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Notes App</title>
</head>
<body>
  {{notes}}
</body>
</html>
```

The `{{notes}}` placeholder will later be replaced with actual notes.

## Server Module

```js
import fs from 'node:fs/promises'
import http from 'node:http'
import open from 'open'

const interpolate = (html, data) => {
  return html.replace(/\{\{\s*(\w+)\s*\}\}/g, (match, placeholder) => {
    return data[placeholder] || ''
  })
}

const formatNotes = (notes) => {
  return notes.map(note => {
    return `
      <div class="note">
        <p>${note.content}</p>
        <div class="tags">
          ${note.tags.map(tag => `<span class="tag">${tag}</span>`).join('')}
        </div>
      </div>
    `
  }).join('\n')
}

const createServer = (notes) => {
  return http.createServer(async (req, res) => {
    const HTML_PATH = new URL('./template.html', import.meta.url).pathname

    const template = await fs.readFile(HTML_PATH, 'utf-8')

    const html = interpolate(template, {
      notes: formatNotes(notes)
    })

    res.writeHead(200, {
      'Content-Type': 'text/html'
    })

    res.end(html)
  })
}

export const start = (notes, port) => {
  const server = createServer(notes)

  server.listen(port, () => {
    console.log(`Server is listening on port ${port}`)
  })

  open(`http://localhost:${port}`)
}
```

## 1. `interpolate()` Function

```js
const interpolate = (html, data) => {
  return html.replace(/\{\{\s*(\w+)\s*\}\}/g, (match, placeholder) => {
    return data[placeholder] || ''
  })
}
```

### Purpose

Replaces placeholders in HTML with actual data.

Example:

```html
<h1>{{title}}</h1>
```

Data:

```js
{
  title: 'My Notes'
}
```

Result:

```html
<h1>My Notes</h1>
```

### Why Use It?

Instead of hardcoding values inside HTML, you can dynamically insert data.

---

## 2. `formatNotes()` Function

```js
const formatNotes = (notes) => {
  return notes.map(note => {
    return `
      <div class="note">
        <p>${note.content}</p>
        <div class="tags">
          ${note.tags.map(tag => `<span class="tag">${tag}</span>`).join('')}
        </div>
      </div>
    `
  }).join('\n')
}
```

### Purpose

Converts note objects into HTML.

Example Note:

```js
{
  content: 'Learn Node.js',
  tags: ['javascript', 'backend']
}
```

Generated HTML:

```html
<div class="note">
  <p>Learn Node.js</p>
  <div class="tags">
    <span class="tag">javascript</span>
    <span class="tag">backend</span>
  </div>
</div>
```

### Why Use It?

Browsers understand HTML, not JavaScript objects. This function converts note data into HTML.

## 3. `createServer()` Function

```js
const createServer = (notes) => {
  return http.createServer(async (req, res) => {
    const HTML_PATH = new URL('./template.html', import.meta.url).pathname

    const template = await fs.readFile(HTML_PATH, 'utf-8')

    const html = interpolate(template, {
      notes: formatNotes(notes)
    })

    res.writeHead(200, {
      'Content-Type': 'text/html'
    })

    res.end(html)
  })
}
```

### Purpose

Creates a web server.

### What Happens?

#### Step 1: Find Template File

```js
const HTML_PATH = new URL('./template.html', import.meta.url).pathname
```

Gets the absolute path to `template.html`.

#### Step 2: Read Template

```js
const template = await fs.readFile(HTML_PATH, 'utf-8')
```

Loads the HTML file.

#### Step 3: Insert Notes

```js
const html = interpolate(template, {
  notes: formatNotes(notes)
})
```

Replaces:

```html
{{notes}}
```

with generated note HTML.

#### Step 4: Send Response

```js
res.writeHead(200, {
  'Content-Type': 'text/html'
})
```

Tells the browser:

> "I'm sending HTML."

#### Step 5: Return HTML

```js
res.end(html)
```

Sends the completed webpage.

Example:


```js

```

Automatically launches the website.

# Key Concepts Learned

* `http.createServer()` creates a web server.
* `fs.readFile()` reads the HTML template.
* `interpolate()` replaces placeholders with data.
* `formatNotes()` converts note objects into HTML.
* `res.writeHead()` sets response headers.
* `res.end()` sends data to the browser.
* `server.listen()` starts the server.
* `open()` launches the browser automatically.
* `new URL(..., import.meta.url).pathname` creates a reliable file path in ES Modules.
