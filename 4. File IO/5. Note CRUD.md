# Note CRUD — Simple Summary

**CRUD** stands for **Create, Read, Update, and Delete**. These are the four basic operations used to manage data in an application.

In this notes app, the data is stored inside a `db.json` file, and CRUD operations allow us to create, read, search, and delete notes.

---

## Key CRUD Operations

### Create

Add a new note to the database.

### Read

Retrieve one or more notes from the database.

### Update

Modify an existing note.

> Note: An update function has not been created yet in these notes.

### Delete

Remove a note (or all notes) from the database.

---

## Notes Module (`notes.js`)

This file contains helper functions that work with notes using the database functions from `db.js`.

```js
import { insert, getDB, saveDB } from './db.js'

export const newNote = async (note, tags) => {
  const data = {
    tags,
    content: note,
    id: Date.now(),
  }

  await insert(data)
  return data
}

export const getAllNotes = async () => {
  const db = await getDB()
  return db.notes
}

export const findNotes = async (filter) => {
  const notes = await getAllNotes()

  return notes.filter(note =>
    note.content.toLowerCase().includes(filter.toLowerCase())
  )
}

export const removeNote = async (id) => {
  const notes = await getAllNotes()
  const match = notes.find(note => note.id === id)

  if (match) {
    const newNotes = notes.filter(note => note.id !== id)

    await saveDB({ notes: newNotes })

    return id
  }
}

export const removeAllNotes = async () => {
  await saveDB({ notes: [] })
}
```

## How the Module Works

The module imports three database helper functions:

```js
import { insert, getDB, saveDB } from './db.js'
```

These functions allow us to:

* Add data to the database
* Read data from the database
* Save changes back to the database

---

## `newNote()`

Creates and saves a new note.

```js
export const newNote = async (note, tags) => {
  const data = {
    tags,
    content: note,
    id: Date.now(),
  }

  await insert(data)
  return data
}
```

### What it does

1. Creates a note object
2. Adds:

   * `content`
   * `tags`
   * unique `id`
3. Saves the note using `insert()`
4. Returns the new note

### Example Result

```js
{
  id: 1717400000000,
  content: 'Learn Node.js',
  tags: ['node', 'javascript']
}
```

### Why `Date.now()`?

```js
id: Date.now()
```

Creates a unique timestamp that can be used as a note ID.

---

## `getAllNotes()`

Returns every note in the database.

```js
export const getAllNotes = async () => {
  const db = await getDB()
  return db.notes
}
```

### What it does

1. Reads the database
2. Returns the `notes` array

### In simple terms

👉 "Give me all notes."

---

## `findNotes()`

Searches notes by text.

```js
export const findNotes = async (filter) => {
  const notes = await getAllNotes()

  return notes.filter(note =>
    note.content.toLowerCase().includes(filter.toLowerCase())
  )
}
```

### What it does

1. Gets all notes
2. Searches note content
3. Returns matching notes

### Why use `toLowerCase()`?

```js
note.content.toLowerCase()
filter.toLowerCase()
```

Makes the search case-insensitive.

Example:

```js
'NodeJS'
'nodejs'
'NODEJS'
```

All match the same search.

### Example

```js
await findNotes('node')
```

Returns all notes containing `"node"`.

---

## `removeNote()`

Deletes a single note.

```js
export const removeNote = async (id) => {
  const notes = await getAllNotes()
  const match = notes.find(note => note.id === id)

  if (match) {
    const newNotes = notes.filter(note => note.id !== id)

    await saveDB({ notes: newNotes })

    return id
  }
}
```

### What it does

1. Gets all notes
2. Finds the note with the given ID
3. Creates a new array without that note
4. Saves the updated notes array
5. Returns the deleted ID

### Example

Before:

```js
[
  { id: 1, content: 'Learn Node' },
  { id: 2, content: 'Learn React' }
]
```

Remove note `1`

After:

```js
[
  { id: 2, content: 'Learn React' }
]
```

---

## `removeAllNotes()`

Deletes every note.

```js
export const removeAllNotes = async () => {
  await saveDB({ notes: [] })
}
```

### What it does

Replaces all notes with an empty array.

### Result

```json
{
  "notes": []
}
```

### In simple terms

👉 "Clear the entire database."

## CRUD Mapping

| CRUD Operation | Function            |
| -------------- | ------------------- |
| Create         | `newNote()`         |
| Read           | `getAllNotes()`     |
| Read/Search    | `findNotes()`       |
| Delete One     | `removeNote()`      |
| Delete All     | `removeAllNotes()`  |
