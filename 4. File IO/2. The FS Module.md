# The FS Module — Simple Summary (ES6 Version)

The **FS (File System) module** is a built-in Node.js module used to work with files and folders. It lets you read, write, create, delete, rename, and inspect files.

In modern Node.js, we use **ES6 imports** instead of `require()`.

---

## Important Setup Note (ES6 in Node.js)

To use ES modules, your `package.json` must include:

```json
{
  "type": "module"
}
```

---

# Full FS Module Examples (ES6 Import)

---

## 1. Reading a File

```js id="fs_read_es6"
import fs from 'fs'

fs.readFile('file.txt', (data) => {
  console.log(data)
})
```

---

## 2. Writing to a File

```js id="fs_write_es6"
import fs from 'fs'

fs.writeFile('file.txt', 'Hello World', () => {
  console.log('File written successfully')
})
```

---

## 3. Creating a Directory

```js id="fs_mkdir_es6"
import fs from 'fs'

fs.mkdir('newFolder', () => {
  console.log('Folder created')
})
```

---

## 4. Reading a Directory

```js id="fs_readdir_es6"
import fs from 'fs'

fs.readdir('.', (files) => {
  console.log(files)
})
```

---

## 5. Getting File Info

```js id="fs_stat_es6"
import fs from 'fs'

fs.stat('file.txt', (info) => {
  console.log(info)
})
```

---

## 6. Deleting a File

```js id="fs_unlink_es6"
import fs from 'fs'

fs.unlink('file.txt', () => {
  console.log('File deleted')
})
```

---

## 7. Renaming a File

```js id="fs_rename_es6"
import fs from 'fs'

fs.rename('old.txt', 'new.txt', () => {
  console.log('File renamed')
})
```

# Better ES6 Version (Recommended): fs/promises

Instead of callbacks, modern Node.js prefers **Promises + async/await**.

---

## Reading a File (Async/Await)

```js id="fs_promises_read"
import fs from 'fs/promises'

async function readFile() {
  const data = await fs.readFile('file.txt')
  console.log(data)
}

readFile()
```

---

## Writing a File

```js id="fs_promises_write"
import fs from 'fs/promises'

await fs.writeFile('file.txt', 'Hello World')
console.log('File written')
```

# Async vs Sync (ES6 Style)

## Async (Recommended)

```js id="fs_async_es6"
import fs from 'fs'

fs.readFile('file.txt', (data) => {
  console.log(data)
})
```

✔ Non-blocking
✔ Better performance
✔ Used in real applications

---

## Sync (Blocking)

```js id="fs_sync_es6"
import fs from 'fs'

const data = fs.readFileSync('file.txt')
console.log(data)
```

❌ Blocks execution
❌ Slower for large apps

---

# Best Practice (Modern Node.js)

Use this when possible:

```js id="fs_best_practice"
import fs from 'fs/promises'

const data = await fs.readFile('file.txt')
console.log(data)
```

---

# One-Sentence Summary

**The FS module in Node.js (using ES6 imports) lets you work with files and folders, and modern Node.js prefers the `fs/promises` API with async/await for cleaner and more efficient code.**
