# The FS Module — Simple Summary (Working ES6 Version)

The **FS (File System) module** is a built-in Node.js module used to work with files and folders. It lets you read, write, create, delete, rename, and inspect files.

In modern Node.js, we use **ES6 imports** instead of `require()`.

# FULL WORKING FS MODULE EXAMPLES (ES6)

---

## 1. Reading a File (WORKING)

```js id="read_file_working"
import fs from 'fs'

fs.readFile('file.txt', 'utf8', (err, data) => {
  if (err) {
    console.error('Error reading file:', err)
    return
  }

  console.log(data)
})
```

---

## 2. Writing to a File (WORKING)

```js id="write_file_working"
import fs from 'fs'

fs.writeFile('file.txt', 'Hello World', (err) => {
  if (err) {
    console.error('Error writing file:', err)
    return
  }

  console.log('File written successfully')
})
```

# PROMISE VERSION (BEST PRACTICE)

## 1. Read Directory (NO NULL, CLEAN OUTPUT)

```js id="readdir_promise"
import fs from 'fs/promises'

async function readFiles() {
  try {
    const files = await fs.readdir('.')
    console.log(files)
  } catch (err) {
    console.error('Error reading directory:', err)
  }
}
```

# One-Sentence Summary

**All FS methods must follow correct Node.js patterns: callbacks use `(err, result)` and modern code should use `fs/promises` with async/await to avoid `null` issues and make code cleaner and safer.**
