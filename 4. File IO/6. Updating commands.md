# Updating Commands — Simple Summary

Now that we have finished creating our note and database functions, we can connect them to our CLI commands.

The commands that previously only existed as placeholders can now perform real actions such as:

* Creating notes
* Listing all notes
* Searching notes
* Deleting notes
* Deleting all notes

The only command that is not implemented yet is the `web` command.

---

## Full Updated CLI Code

```js
import yargs from 'yargs'
import { hideBin } from 'yargs/helpers'
import {
  newNote,
  getAllNotes,
  findNotes,
  removeNote,
  removeAllNotes
} from './notes.js'

const listNotes = (notes) => {
  notes.forEach(note => {
    console.log('\n')
    console.log('id: ', note.id)
    console.log('tags: ', note.tags.join(', '))
    console.log('note: ', note.content)
  })
}

yargs(hideBin(process.argv))

  .command(
    'new <note>',
    'create a new note',
    yargs => {
      return yargs.positional('note', {
        describe: 'The content of the note you want to create',
        type: 'string'
      })
    },
    async (argv) => {
      const tags = argv.tags ? argv.tags.split(',') : []

      const note = await newNote(argv.note, tags)

      console.log('Note added!', note.id)
    }
  )

  .option('tags', {
    alias: 't',
    type: 'string',
    description: 'tags to add to the note'
  })

  .command(
    'all',
    'get all notes',
    () => {},
    async () => {
      const notes = await getAllNotes()
      listNotes(notes)
    }
  )

  .command(
    'find <filter>',
    'get matching notes',
    yargs => {
      return yargs.positional('filter', {
        describe: 'The search term to filter notes by',
        type: 'string'
      })
    },
    async (argv) => {
      const notes = await findNotes(argv.filter)
      listNotes(notes)
    }
  )

  .command(
    'remove <id>',
    'remove a note by id',
    yargs => {
      return yargs.positional('id', {
        type: 'number',
        description: 'The id of the note you want to remove'
      })
    },
    async (argv) => {
      const id = await removeNote(argv.id)

      if (id) {
        console.log('Note removed:', id)
      } else {
        console.log('Note not found')
      }
    }
  )

  .command(
    'web [port]',
    'launch website to see notes',
    yargs => {
      return yargs.positional('port', {
        describe: 'port to bind on',
        default: 5000,
        type: 'number'
      })
    },
    async () => {
      // Not implemented yet
    }
  )

  .command(
    'clean',
    'remove all notes',
    () => {},
    async () => {
      await removeAllNotes()
      console.log('All notes removed')
    }
  )

  .demandCommand(1)
  .parse()
```

## Helper Function: `listNotes()`

```js
const listNotes = (notes) => {
  notes.forEach(note => {
    console.log('\n')
    console.log('id: ', note.id)
    console.log('tags: ', note.tags.join(', '))
    console.log('note: ', note.content)
  })
}
```

### What it does

Displays notes in a readable format.

### Example Output

```text
id: 1717400000000
tags: node, javascript
note: Learn Node.js
```

### Why use it?

Instead of repeating `console.log()` code everywhere, we create one reusable function.

## Command: Create a Note

```js
.command('new <note>', ...)
```

### What it does

Creates a new note.

### Handler

```js
const tags = argv.tags
  ? argv.tags.split(',')
  : []

const note = await newNote(argv.note, tags)
```

### How tags work

```js
argv.tags.split(',')
```

Converts:

```text
node,javascript,backend
```

into:

```js
['node', 'javascript', 'backend']
```

### Example Command

```bash
node src/index.js new "Learn Node.js" --tags node,javascript
```

### Result

```text
Note added! 1717400000000
```

## The `--tags` Option

```js
.option('tags', {
  alias: 't',
  type: 'string'
})
```

### What it does

Allows tags to be added when creating notes.

### Example

```bash
node src/index.js new "Learn Node" --tags node,javascript
```

or

```bash
node src/index.js new "Learn Node" -t node,javascript
```

---

## `.demandCommand(1)`

```js
.demandCommand(1)
```

### What it does

Requires at least one command.

### Example

This will fail:

```bash
node src/index.js
```

Because no command was provided.
